# TP-Grafos

- Trabalho pratico desenvolvido a disciplina de **Teoria dos grafos e computabilidade** do curso de Engenharia de Software da PUC Minas.

- O Trabalho pratico tem o objetivo desenvolver uma ferramenta computacional para resolver um problema aplicado por meio da modelagem, implementação e análise de grafos.

## Linguagem Escolhida

- Python

## Tema escolhido

- Análise de redes de transporte público: construção de grafos baseados em
linhas de onibus, metro ou trem, com simulação de trajetos, tempo de espera e
eficiencia.
